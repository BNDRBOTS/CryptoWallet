# CipherFolio Landing + App

## Files

- `index.html` — SaaS-style landing/product page
- `app.html` — original immutable application file
- `styles.css` — landing page styles only
- `site.js` — landing page behavior only

## Preservation Rule

`app.html` must remain **byte-for-byte identical** to the original supplied app.
Do not edit, reformat, rename IDs, alter scripts, move elements, change CSS, or modify comments inside `app.html`.
