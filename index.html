Capabilities

Built for a private, fast ledger workflow.

Every feature is implemented directly in the app. No hidden servers, no accounts, no tracking.

Local persistence

Portfolio entries are stored in your browser's localStorage. Close the tab, reopen it — your ledger is still there.

Live market sync

Uses the public CryptoCompare endpoint to fetch current USD valuations for each asset you enter.

Allocation analytics

A responsive doughnut chart visualizes your portfolio concentration, with hover tooltips and live data updates.

No account, no API key

The app is fully client-side. No login, no user database, no key management. Just open and track.

Validated entries

Before a ticker is written to the ledger, the app checks it against CryptoCompare and rejects unsupported symbols.

Explicit deletion workflow

A custom confirmation modal protects against accidental purges. Deletion is permanent and under your control.

FAQ

Common questions.

Is my portfolio stored on a server?

No. CipherFolio stores your portfolio in your browser's localStorage. It never sends your holdings to a backend database.

Which assets are supported?

Any ticker that the public CryptoCompare API recognizes as a valid symbol with a USD pair.

What happens if CryptoCompare is unreachable?

The app falls back to the last known entry price for each asset and shows a network warning. Your local ledger remains available.

Do I need to create an account?

No. CipherFolio is a static, client-side application. There is no login, no user system, and no API key to manage.

Can I export or clear my data?

You can delete assets individually via the confirmation modal. Clearing your browser storage removes the ledger. The app does not add remote backups.
